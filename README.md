# Todo List — Тестовое задание

Простой список задач на React + TypeScript + Vite.

## Функциональность

- ➕ Добавление задачи (пустые задачи и задачи из одних пробелов не добавляются)
- ✅ Переключение задачи между выполненной и активной
- 🗑️ Удаление задачи
- 🔍 Фильтрация: все / активные / выполненные
- 💾 Сохранение в `localStorage` — задачи сохраняются после перезагрузки страницы
- 🎨 Выполненные задачи визуально отличаются

## Стек

- **React 19** - библиотека UI
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- Чистый CSS (без UI-библиотек)

## Запуск

Требуется **Node.js 18+** и **npm**.

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev
```

Приложение откроется по адресу http://localhost:5173.

Сборка production-версии

```bash
npm run build
```
Готовые файлы появятся в папке dist/. Предпросмотр сборки:

```bash
npm run preview
```

## Структура проекта
src/
├── App.tsx       — основной компонент (вся логика)
├── App.css       — стили компонента
├── index.css     — глобальные стили и CSS-переменные
└── main.tsx      — точка входа

## Как хранятся данные
Задачи хранятся в localStorage браузера под ключом todos в виде JSON-массива:

```json
[
  { "id": 1730000000000, "text": "Купить хлеб", "completed": false }
]
```

Данные читаются при старте приложения и записываются при каждом изменении списка.
